# DxMinecraft

A simple Minecraft clone implemented using DirectX 12.

## Overview

DxMinecraft is a voxel-based sandbox project inspired by Minecraft. It focuses on rendering, chunk management, and low-level graphics programming using DirectX 12.

## Features

* Chunk-based voxel world
* Basic terrain generation
* Real-time rendering with DirectX 12
* Written in modern C++ (C++23)

## Getting Started

### Prerequisites

Ensure you have the following installed:

* Visual Studio 2026
* Desktop Development with C++ workload
* Windows 10/11 SDK

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Vercyx09/DxMinecraft.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DxMinecraft
   ```

3. Run the setup script:

   ```bat
   Setup.bat
   ```

4. Open the solution file:

   ```
   DxMinecraft.slnx
   ```

5. Build and run the project using Visual Studio.

## Controls

* **W/A/S/D** – Move
* **Mouse** – Look around
* **Space** – Jump
* **Shift** – Sneak
* **Double space** – Fly
